05 — PositioningStrategy Notes for the IE + CS Combo

Lead with IE, mention CS as a differentiator

For manufacturing/supply-chain roles (GM, Ford, P&G, Caterpillar, UPS), the CS minor is a resume differentiator — mention SQL/Python/data tooling in the application, but apply through the IE/Ops req, not the SWE one.

Amazon is the strongest single dual-fit

Amazon is unusual in running large IE-adjacent Ops/Supply Chain internship classes alongside its SDE program at comparable scale — worth applying to both reqs there specifically.

Consulting ops practice as a stretch

McKinsey/BCG/Bain and Deloitte/Accenture all run operations-focused case tracks that recruit IE majors directly, not just finance/econ students — the McKinsey deadline this week is the most concrete entry point.

Recheck the "not yet" rows monthly

Most of the industrial/manufacturing rows above (Boeing, GM, Ford, Honeywell, 3M, GE, Lockheed) cluster around an August-October 2026 open window — a single monthly pass through this table from September through December should catch nearly all of them.

09 — Before hitting submitResume Format

Short answer: yes, and one resume won't cover everything here — tech, industrial/manufacturing, and consulting recruiters read resumes differently enough that he should keep 2-3 tailored versions rather than one generic copy.

Baseline, true for every version: one page, reverse chronological, single-column with no tables/graphics/photo/text boxes (ATS parsers choke on multi-column layouts), quantified bullets with action verbs, Education section with major, minor, expected graduation, GPA, and relevant coursework.

Tech / SWE track (Amazon, Google, Microsoft, Meta, NVIDIA)

Projects lead, not experience — for interns, personal/class projects are the experience. Group technical skills by category (Languages, Frameworks, Tools). Name real technologies and outcomes, never "developed a web application."

IE / Ops / Manufacturing track (GM, Ford, Boeing ops, Caterpillar, P&G, UPS)

Surface Excel, SQL, Minitab, and lean/Six Sigma vocabulary directly — Value Stream Mapping, 5S, Kaizen, Kanban, SMED. List in-progress coursework, not just completed classes, since ISE curriculum (statistics, ops research, ergonomics) is itself a qualification here.

Consulting track (McKinsey, BCG, Bain)

Meaningfully different structure: Education comes first (even above experience), then Experience, then Leadership/Activities. Strictly one page — a second page is an auto-reject at all three firms, even for undergrads. Black-and-white only, zero color or graphics. Bullets follow Context-Action-Result with a % or $ figure, not a duty description. Given the McKinsey deadline above, this version needs to exist first if he's applying there.

Defense-adjacent roles (Boeing, Lockheed Martin)

Not a format change so much as a line item: since these employers require U.S. Person status and don't sponsor visas, citizenship status is worth stating plainly (most students just note "U.S. Citizen"). If he ever holds an active or interim security clearance, that line goes directly under his name/contact info, ahead of everything else — not relevant yet, but worth knowing for later.

Concrete next step: VT's CPD office provides VMock, a free 24/7 tool that scores a resume on Impact/Presentation/Competencies, checks ATS-compatibility, and can compare the resume against a specific job description — worth running each tailored version through before he applies, and faster than waiting for a human review appointment.
